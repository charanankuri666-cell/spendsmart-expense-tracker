# SpendSmart — Student Expense Tracker

A responsive beginner portfolio project built with HTML, CSS, and vanilla JavaScript.

## Features
- Record income and expenses with dates, categories, and notes
- Dashboard with balance, income, expenses, and remaining budget
- Category-wise spending donut chart
- Monthly filter and budget progress warnings
- Search and filter transactions
- Delete transactions and export CSV
- Persists data in browser localStorage
- Responsive layout for mobile and desktop

## Run it
1. Extract the ZIP.
2. Open the `SpendSmart` folder.
3. Double-click `index.html` to launch it in your browser.

No installation is needed.

## Project files
- `index.html` — layout and forms
- `style.css` — responsive visual design
- `app.js` — application logic and browser storage

## Privacy note
This demo stores records in localStorage on the current browser/device and does not send them to a server. Clearing browser site data may remove them.
